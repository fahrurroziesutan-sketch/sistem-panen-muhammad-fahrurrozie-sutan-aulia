# Sistem Pencatatan Hasil Panen Digital

## Deskripsi Singkat
Proyek ini merupakan sistem berbasis Python untuk mengelola dan mencatat hasil panen pertanian, termasuk fitur penghitungan total nilai panen serta kalkulasi diskon hasil produksi untuk mendukung operasional agroindustri yang efisien.

## Cara Menjalankan Program
1. Pastikan Python sudah terinstal di komputer Anda.
2. Unduh atau klon repositori ini ke perangkat lokal Anda.
3. Jalankan program melalui terminal menggunakan perintah:
   ```bash
   python panen.py
